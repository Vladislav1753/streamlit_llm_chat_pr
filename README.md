# Streamlit LLM Chat Recommender

Welcome to my small streamlit project!

This is a simple Streamlit application that uses the **Gemini 2.0 Flash** model to recommend artistic content such as **films, books, anime, and series**. The assistant responds to user queries with curated suggestions and brief descriptions.

**The link to the application itself: https://vladislav1753-streamlit-llm-chat-pr-app-mpjmip.streamlit.app/**

## Features

- Chat interface powered by [Streamlit](https://streamlit.io)
- Content recommendations using Google's `generativeai` API
- Adjustable temperature for controlling creativity
- Chat history management with reset option
- Local or cloud-based secret management

## Project Structure

- `app.py` — main Streamlit app with chat interface and logic  
- `functions.py` — utility functions for secret retrieval and session reset

## Requirements

Install dependencies using:

```bash
pip install -r requirements.txt
```
